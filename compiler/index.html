Tempel dari Excel

Salin blok sel dari Excel (baris = vessel, kolom = titik waktu; baris judul menit boleh ikut), lalu tempel di sini. Angka dengan koma desimal dikenali.

Impor sheet lama

Pilih berkas .xlsx sheet lama (maks 4 MB). Periksa dulu: laporan pencocokan ditampilkan tanpa menyimpan apa pun.

Identitas run

Identitas run = produk + batch + varian + medium + data vessel. Tanggal tidak termasuk identitas.

% terlarut per vessel

Maksimum 12 vessel dan 9 titik waktu
Batas RSD: 20% untuk titik ≤ 10 menit, 10% untuk titik lainnya.
